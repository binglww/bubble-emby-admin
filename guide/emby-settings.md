# Emby 设置

## 基础连接

`Emby 设置` 属于系统的必要配置。未完成该页基础连接前，账号同步、权限模板和依赖 Emby 的相关能力无法正常使用。

### Emby 地址

`Emby 地址` 需要填写完整协议头，例如 `http://127.0.0.1:8096` 或 `https://example.com`。

### API Key

`API Key` 用于后台访问 Emby 接口。保存后，系统会使用该地址和密钥建立连接。

## Webhook 配置

### 启用 Emby Webhook

`启用 Emby Webhook` 用于接收 Emby 回调事件。

### Webhook 密钥

`Webhook 密钥` 用于校验 Emby 回调请求。留空时，保存配置时可自动生成。

### Webhook 地址

`Webhook 地址` 由系统生成，可直接复制到 Emby Webhook 配置中。

该地址已支持媒体入库后的求片联动。若 Emby 与本系统都运行在 Docker 中，地址中的主机名需要替换为容器之间可访问的地址。

## 基础用户权限模板

`基础用户权限模板` 用于定义新用户的 Emby 权限。

- 网页注册用户会自动使用默认模板
- 后台创建用户时可改选其他模板
- 模板内容按 `播放`、`功能访问`、`遥控`、`下载`、`字幕`、`其他`、`并发与码率` 分组维护

模板只在创建用户时生效，不会回写已经存在的 Emby 用户。

## 首次同步与日常维护

如果 Emby 中已经存在历史用户，首次接入本系统后，建议先前往 `用户管理` 执行一次 `同步用户`。

这一步会把 Emby 当前已有用户写入本系统的本地用户表，为后续的到期控制、续费、通知和状态展示建立基础数据。

完成首次同步后，建议优先通过本系统管理用户：

- 创建用户
- 禁用或启用用户
- 续费和调整到期时间
- 删除用户

`同步用户` 会把 Emby 当前仍存在的用户写回本地，但不会根据 Emby 的缺失用户自动删除本地记录。直接在 Emby 删除用户，不会自动同步回本系统。

## 恢复用户

`恢复用户` 适用于 Emby 被重置后的恢复场景。

- 系统会按本地数据库重建缺失用户
- 同名用户会直接跳过
- 成功恢复的用户会生成新密码
- 处理结果通过 CSV 导出
