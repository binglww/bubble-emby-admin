# 系统介绍

Bubble Emby Admin 是一套面向 Emby 管理场景的后台系统，核心目标是把用户、会员、续费、通知和用户入口集中到同一套管理流程中。

> 系统仍在快速更新迭代中。如遇到 Bug 或使用问题，请及时在 [GitHub](https://github.com/binglww/bubble-emby-admin/issues) 反馈。

## 主要功能

### 用户与会员管理

- 同步 Emby 现有用户到本系统
- 创建用户、启用用户、禁用用户、删除用户
- 批量续费、批量删除、批量禁用、批量同步权限
- 白名单管理
- 到期禁用、到期删除和状态同步

### 用户入口

- 网页登录
- 网页注册
- 卡密续费
- 会员信息展示
- 上次活动、最近 30 天观看时长、设备和 IP 信息
- 服务器线路展示与快捷导入

### 求片系统

- 电影求片
- 整剧求片
- 单季求片
- TMDB 搜索和热门推荐
- 我的求片记录
- 用户求片次数限制
- MoviePilot 推送
- Emby Webhook 自动闭环

### Emby 管理

- Emby 地址和 API Key 配置
- Emby Webhook 配置
- 基础用户权限模板
- 批量同步权限
- 从本地恢复用户到 Emby
- Emby 简易探针

### Telegram 集成

- Telegram Bot 基础接入
- Telegram HTTP 代理
- Telegram Mini App
- Telegram 自定义指令
- Telegram 快捷求片与求片处理
- 用户绑定和管理员绑定
- 管理员通知
- 菜单按钮和群组校验

### 卡密、注册与公告

- 续费卡密
- 注册卡密
- 公开注册
- 定时注册
- 限量注册
- 邀请码注册
- 公告管理

### 线路、统计与风控

- 独立线路管理
- 线路显示开关和白名单可见
- 播放统计
- Emby `/Sessions` 实时会话
- 热门内容排行
- 设备分析与客户端分布
- 客户端黑名单
- 流量防护
