# 通知

`通知` 位于后台 `配置中心` 中，用于维护通知事件开关和通知模板。

后台入口：`配置中心` -> `通知`

当前通知渠道仅支持 Telegram。Telegram Bot 连接、管理员通知总开关和已绑定管理员列表在 `配置中心` -> `Telegram` 中维护。

## 通知开关

`通知开关` 用于控制哪些事件会触发通知。

页面分为两类事件：

- `管理员通知`：发送给已绑定 Telegram 且开启个人接收偏好的管理员
- `用户通知`：发送给对应用户绑定的 Telegram 账号

全局未开启的事件不会发送。管理员个人接收偏好关闭的事件，也不会发送给该管理员本人。

## 管理员通知

管理员通知需要同时满足以下条件：

- `配置中心` -> `Telegram` -> `管理员通知` 中已开启 `通过 Telegram 接收管理员通知`
- `配置中心` -> `通知` 中对应的管理员通知事件已开启
- 管理员本人已经在 `个人设置` 中完成 Telegram 绑定
- 管理员本人的 `我的通知接收` 中开启了对应事件

常见管理员通知事件包括：

- `求片通知`
- `工单通知`
- `客户端黑名单命中通知`
- `批量任务完成/失败/部分成功`
- `自助注册/续费兑换成功`
- `Emby 状态同步失败告警`
- `管理员手动创建用户通知`
- `安全/风控类异常`

## 用户通知

用户通知用于向用户本人发送账号相关提醒。

例如用户注册、续费、到期处理、保号自动续费等事件，都会按对应事件开关和模板配置决定是否发送。

用户通知能否实际发送，还取决于用户是否已经绑定 Telegram。

## 通知模板

`通知模板` Tab 用于维护不同通知事件的消息内容。

模板编辑区支持：

- 查看模板变量
- 编辑通知内容
- 预览模板渲染结果
- 保存当前模板
- 恢复默认模板

模板内容建议先预览再保存，避免 Telegram `MarkdownV2` 转义或变量缺失导致发送结果不符合预期。

## 工单通知

工单通知属于管理员通知，支持以下模板：

- `管理员新工单通知`
- `工单用户补充通知`

工单通知除全局通知开关和个人接收偏好外，还受工单类型接收人配置控制。只有该工单类型中配置的有效管理员，且已绑定 Telegram 并开启个人 `工单通知` 偏好，才会收到消息。

触发通知的动作：

- 用户提交新工单
- 用户补充工单

不会触发通知的动作：

- 管理员回复
- 用户关闭
- 管理员关闭

工单图片不会直接进入 Telegram 消息模板。消息中可包含后台工单详情链接，管理员点击后进入对应工单详情。

## 管理员绑定

管理员的 Telegram 绑定在 `个人设置` 页面处理。

`我的 Telegram 绑定` 提供以下能力：

- 生成绑定链接
- 发送测试消息
- 解除绑定
- 刷新绑定状态

只有已绑定 Telegram 的管理员，才可能接收管理员通知。

## 已绑定管理员列表

`配置中心` -> `Telegram` -> `管理员通知` 会显示当前 Bot 已绑定的管理员列表，用于核对：

- 管理员账号
- Telegram 用户名
- Chat ID
- Telegram 账号状态
- 更新时间

该列表用于查看当前绑定状态，不用于代替个人绑定设置。
