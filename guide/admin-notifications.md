# 管理员通知

## 全局开关

管理员通知由两部分共同决定。

- Telegram 设置中的 `通过 Telegram 接收管理员通知`
- 通知配置页中的管理员通知事件开关

当前通知渠道仅支持 Telegram。

## 管理员通知事件

管理员通知事件在 `通知配置` 页面维护，常见项目包括：

- `求片通知`
- `客户端黑名单命中通知`
- `批量任务完成/失败/部分成功`
- `自助注册/续费兑换成功`
- `Emby 状态同步失败告警`
- `管理员手动创建用户通知`
- `安全/风控类异常`

全局未开启的事件，不会发送给任何管理员。

## 管理员绑定

管理员的 Telegram 绑定在 `个人设置` 页面处理。

`我的 Telegram 绑定` 提供以下能力：

- 生成绑定链接
- 发送测试消息
- 解除绑定
- 刷新绑定状态

只有已绑定 Telegram 的管理员，才可能接收管理员通知。

## 个人接收偏好

`我的通知接收` 用于控制当前管理员本人接收哪些通知。

- 只有系统全局通知已开启，并且当前账号已绑定 Telegram 时，通知才会实际发送
- 全局未开启的项目，在个人接收偏好中会显示为不可用

## 已绑定管理员列表

`Telegram 设置` 页面会显示当前 Bot 已绑定的管理员列表，用于核对：

- 管理员账号
- Telegram 用户名
- Chat ID
- Telegram 账号状态
- 更新时间

该列表用于查看当前绑定状态，不用于代替个人绑定设置。
